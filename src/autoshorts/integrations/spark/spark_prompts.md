# Gemini Spark Integration & Prompt Templates

> **ECOSYSTEM STATUS & ARCHITECTURAL REALITY (PLAN.md Section 5.6)**:
> As of late 2026, Google provides **NO public REST API, SDK, or MCP server** for third-party programmatic execution of Gemini Spark. Spark is a managed, autonomous personal AI agent operating within Google Workspace (Gmail, Drive, Docs) and Chrome.
>
> Any direct programmatic API automation of Spark is classified as **UNVERIFIED / FUTURE**. AutoShorts integrates with Spark via a **loosely coupled companion workflow**:
> 1. Ready-to-paste Spark Skill prompt templates (below).
> 2. Watched `inbox/` hand-off folder (e.g. synced via Google Drive on Windows).
> 3. Dashboard "Import from Gemini Spark" paste box.

---

## 1. Spark Skill 1: Viral Short Curator

Copy and paste this into Gemini Spark's persistent instructions or conversation window:

```text
[GEMINI SPARK SKILL: VIRAL SHORT CURATOR]
Role: You are an autonomous YouTube Shorts research agent.
Goal: Monitor selected YouTube channels or search for high-retention long-form videos on topic: {TOPIC}.

Instructions:
1. Identify high-engagement videos released in the past 7 days with duration > 10 minutes.
2. For each video, locate 1 to 2 standalone viral segments (30-55 seconds) with high curiosity hooks, surprising revelations, or emotional peaks.
3. For each candidate segment, format your findings strictly as this JSON block:
{
  "source_url": "https://www.youtube.com/watch?v=VIDEO_ID",
  "clip_title": "Descriptive Topic Hook",
  "start_time": "MM:SS",
  "end_time": "MM:SS",
  "hook_text": "First 3-second hook question",
  "target_background": "minecraft",
  "notes": "Key punchline occurs at MM:SS"
}
```

## 3. Ingestion Methods

### Method A: Monitored Drop Folder (`inbox/`)
1. Configure Gemini Spark to save findings as a `.json` or `.md` file to a Google Drive folder.
2. Sync that Google Drive folder to your Windows PC inside the AutoShorts root directory: `./inbox/`.
3. AutoShorts `SparkInboxWatcher` automatically ingests new files, enqueues them in SQLite (`state.db`), and moves processed files to `./inbox/processed/` (or `./inbox/failed/` if invalid).

### Method B: Dashboard Paste Box
1. Copy the output generated by Gemini Spark.
2. Open the AutoShorts web dashboard (`http://localhost:8765`).
3. Click **"Import from Gemini Spark"** and paste the JSON or Markdown text.
4. AutoShorts parses the URLs, start/end timestamps, and hook cards immediately into your queue.
